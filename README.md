# 🧪 Sandbox: форма входа

Учебный проект-песочница: адаптивная страница входа и скрипт на TypeScript, где я практикую типизацию и работу с DOM.

## Что внутри

| Файл | Назначение |
|------|-----------|
| `index.html` | Разметка и стили формы входа (email, пароль, ссылка «Забыли пароль?») |
| `login.ts` | Логика формы на TypeScript |
| `login.js` | Скомпилированная версия `login.ts`, подключается в `index.html` |

## Как это работает

- Интерфейс `User` описывает пользователя: `id`, `name`, `email` и `role` (`admin`, `user` или `guest`).
- При отправке формы email очищается от лишних пробелов, и пользователю назначается роль:
  - пустой email → `guest`
  - `admin@test.com` → `admin`
  - любой другой email → `user`
- Функция `getWelcomeMessage` возвращает приветствие под роль и показывает его через `alert`.
- Элементы DOM проверяются на `null`, так что код не падает, если их нет на странице.

> ⚠️ Это демо. Настоящей авторизации нет: пароль не проверяется и никуда не отправляется.

## Запуск

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/halimaaltyn2026/sandbox.git
   ```
2. Откройте `index.html` в браузере.

Если меняете `login.ts`, пересоберите JS:
```bash
npx tsc login.ts
```
